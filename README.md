# FutureMe Lab — Beginner’s Guide

Explore careers through 50 multiple-choice questions and three miniature career missions. This guide is for students, parents, and teachers, including people who have never run an application before.

**No coding, software installation, AI subscription, or API key is needed to use the app.**

## Choose how to start

- **Use it on your computer:** follow Option 1 below.
- **Put it online and share a link:** follow Option 2 below.
- **Learn what to click:** see “Using the application.”
- **Something is not working:** see “Troubleshooting.”

## Option 1: Download and open — no coding

You need a computer and a browser such as Chrome, Edge, Firefox, or Safari. An internet connection is needed to download the files.

1. Open [the Futurelab repository](https://github.com/dpjegankumar/futurelab).
2. Select the **Code** tab if necessary.
3. Click the **Code** button above the file list, then choose **Download ZIP**.
4. Find **futurelab-main.zip** in your **Downloads** folder.
5. Extract the ZIP before opening the app:
   - **Windows:** right-click the ZIP → **Extract All…** → **Extract**.
   - **Mac:** double-click the ZIP to extract it.
6. Open the extracted **futurelab-main** folder. If another folder with that name is inside it, open that too.
7. Double-click **index.html**. If file extensions are hidden, it may appear as **index** with a browser icon.
8. If it opens in a text editor, right-click it → **Open with** → select your browser.
9. You should see **FutureMe Lab** and the heading **“Less guessing. More ‘this is me.’”** Begin with the grade or age form.

**Keep `index.html`, `style.css`, `app.js`, and `explorer.js` together in the same folder.** Moving only the HTML file will break the app.

To return later, reopen the same **index.html** in the same browser. You can bookmark it or create a shortcut. Once downloaded, the core app can work without internet; web fonts may fall back to your computer’s fonts.

Some browsers restrict saving when opening files directly. For more consistent browser storage, use the hosted website described next.

## Option 2: Publish with GitHub Pages — no coding

This creates a website visitors can open without downloading anything. The repository owner, or someone with suitable permissions, must do the setup. A GitHub Pages website is generally public.

1. Sign in to GitHub as **dpjegankumar**.
2. Open [futurelab](https://github.com/dpjegankumar/futurelab).
3. Open the repository’s **Settings** tab. On a narrow screen, look in the **…** menu.
4. Select **Pages** in the settings sidebar.
5. Find **Build and deployment** and set **Source** to **Deploy from a branch**.
6. Under **Branch**, select **main**. In the folder dropdown, select **/ (root)**.
7. Click **Save** and allow time for publication.
8. Refresh the **Pages** settings screen. When publication succeeds, click its website link or **Visit site**.

The expected website address for this repository is:

**https://dpjegankumar.github.io/futurelab/**

This address is not confirmation that Pages is already enabled. Check the status in **Settings → Pages** first. After it is published, open the website and confirm that the career explorer and missions appear. You can then bookmark or share the link. Visitors do not need a GitHub account for a public Pages website.

If publishing fails, open the repository’s **Actions** tab and check the latest Pages deployment for an error.

Official instructions: [Configure a publishing source for GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Using the application

### Step 1: Set your grade or age

1. Find **“What stage are you at?”** on the home screen.
2. Under **Tell us your**, choose **Current grade** or **Age**.
3. Select your grade or age and click **Save and continue**.
4. Later, use **Change grade / age** on the missions screen or **Change grade or age** in the explorer to edit it.

Current options cover grades 6–12, college/further study, beyond school, and ages 10–25+. These select learning difficulty; they do not determine who can pursue a career.

### Step 2: Explore careers with 50 questions

1. Click **Career explorer** in the top menu or **Find my career directions** on the home screen.
2. Imagine yourself trying each activity, even if it is new to you.
3. Choose one of five answers, from **Not for me** to **I’d love to do this**. There are no correct answers.
4. Answer all five questions on the page, then click **Next five questions**.
5. Continue through all ten pages. Use **Previous** to revisit an earlier page.
6. On the final page, click **Discover my career directions**.
7. Read the three suggested directions, the answers behind them, and the suggested experiments.
8. To revise answers, select **Review my answers**, make changes, and continue through the pages to generate updated results.

Your answers save automatically when browser storage is available. To pause, close the tab. Reopen the same app in the same browser and select **Career explorer** to resume.

The six interest areas are software, design, business, science, people-focused work, and engineering. Suggestions describe interests, not proven ability or a final career decision.

### Step 3: Choose a suitable mission

1. Select **Explore missions**.
2. The default **My grade / age** filter shows missions for your saved learning level.
3. Use **Show missions for** to browse a specific grade or **All eligibility levels**.
4. Read the eligibility label on the card before starting.

| Mission | Career area | Eligible learning level |
| --- | --- | --- |
| A smoother ride to school | Product design | Grade 6+ or age 11+ |
| The case of the broken sign-up | Software development | Grade 7+ or age 12+ |
| The café customer mystery | Business analysis | Grade 9+ or age 14+ |

Eligibility uses whichever you supplied: grade or age. Browsing another grade does not change your saved details or unlock a mission outside your current level. If no missions are available, you can still answer the questionnaire and try the small experiments suggested in its results.

### Step 4: Complete a mission

1. Click **Try this career**, **Continue mission**, or **Revisit mission**.
2. Read the brief and the supplied clues, research, or figures.
3. Answer both multiple-choice questions.
4. Select **Need a hint?** if you want support.
5. Explain your reasoning in the text box using at least **20 characters**.
6. Choose how much you enjoyed the work.
7. Click **See what I discovered** and read your feedback.

Drafts save while you work, so you can close a mission and return later. Repeating and submitting a mission replaces its previous result in your profile.

### Step 5: Review your discoveries

- **My skills profile:** see completed missions, evidence from your choices, reflections, and enjoyment ratings.
- **Download my journal:** save a text report in your Downloads folder. It includes mission feedback and reflections. It is not a restorable backup and does not export questionnaire answers.
- **My next steps:** see three experiments based on completed missions and enjoyment. Tick **I tried this** as you complete them.
- **Meet Alex / Meet Sam:** explore sample students with different approaches. These demonstrations do not change your profile.

Complete at least one mission to populate mission feedback and the mission-based next-step plan. Questionnaire career suggestions are available separately in **Career explorer**.

## Saving progress and using shared computers

- Progress stays in this browser on this device. This MVP has no account system or cloud sync.
- Another browser, device, browser profile, or website address has separate progress. The downloaded app and hosted versions do not share results.
- Private/incognito browsing may discard progress when closed. Clearing browser site data removes saved answers and results.
- Moving or renaming a downloaded app folder may affect access to its saved progress.
- Students using the same browser profile share the same app progress. Use separate browser profiles or devices for separate students.
- To start over, download any journal you want to keep, then remove this app’s stored data using your browser’s site-data settings. This removes its saved grade/age, answers, results, and checklists.
- No name or date of birth is required. Fonts load from Google Fonts when internet is available.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| I see GitHub files, not the app | Download and extract the ZIP, then open `index.html`, or use the published Pages address. |
| I see code instead of a webpage | Right-click `index.html` and use **Open with** to choose a browser. |
| The page has no styling or its buttons do nothing | Extract the ZIP first and keep all four app files together. Open `index.html`, not `README.md` or a JavaScript file. |
| The next-question button will not continue | Select one answer for each of the five questions. Scroll to find any unanswered question. |
| A mission will not submit | Answer both questions, explain your reasoning in at least 20 characters, and choose an enjoyment rating. |
| A mission is missing | Check its eligible learning level and the current grade filter. Change your saved grade/age only if it is incorrect. |
| My skills profile is empty | Submit a mission. The questionnaire alone does not create mission evidence. |
| My progress disappeared | Check the device, browser profile, and app address. Avoid private mode. A journal download cannot restore cleared browser data. |
| I see “Storage is unavailable” | Keep the tab open for this session. Try a normal browser window, allow site storage, or use the hosted website. |
| The Pages address shows 404 | Confirm publication succeeded, the source is `main` and `/ (root)`, and `index.html` is at the repository root. Include `/futurelab/` in the address. |
| I cannot save Pages settings | Sign in as the owner or ask the owner to configure Pages. |
| A recent update is missing | Wait for Pages deployment to finish, then refresh. For a downloaded copy, download and extract a fresh ZIP. |

## Optional technical reference

Everyday users can skip this section. The app uses plain HTML, CSS, and JavaScript, with no build step or dependency installation.

| File | Purpose |
| --- | --- |
| `index.html` | The webpage to open |
| `style.css` | Layout, colors, and responsive styling |
| `app.js` | Missions, profiles, feedback, and journal download |
| `explorer.js` | Questionnaire, career suggestions, grade/age setup, and filters |
| `verify.cjs` | Automated checks for question count, scoring, and eligibility |

If Node.js is already installed, open a terminal in this folder and run:

```sh
node verify.cjs
```

Expected result: `Verified: 50 unique questions, normalized recommendations, and grade/age eligibility boundaries.`

## Current scope

The app contains all 50 questions, six career interest areas, and three full missions. Science, people-focused work, and engineering currently suggest small experiments rather than full in-app missions. Mission feedback uses authored rules, with no live AI assessment. Compare questionnaire preferences with actual mission experiences as you explore possible next steps.
